# React + Vite

**Homework**

**Завдання: Менеджер замовлень**

Створіть Redux додаток для управління списком замовлень в інтернет-магазині. Ваш додаток має мати такі можливості:

1. **Створення замовлення:** Користувач може додати нове замовлення, вказавши продукти та кількість кожного з них.

2. **Перегляд списку замовлень:** Всі створені замовлення повинні відображатись на екрані з можливістю перегляду деталей
   кожного замовлення.

3. **Редагування замовлення:** Користувач може змінити список продуктів у будь-якому замовленні.

4. **Видалення замовлення:** Користувач може видалити будь-яке замовлення зі списку.

5. **Обробка стану через Redux:** Всі замовлення та їхні зміни повинні оброблятись через Redux стор.

Це завдання дозволить вам поглибити розуміння управління станом за допомогою Redux, роботу з дієвими діями (actions),
редукторами (reducers) і підключенням до React компонентів.
